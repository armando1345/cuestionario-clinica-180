# Cuestionario Clínica 180°

Sitio estático listo para GitHub Pages. No necesita compilación, paquetes ni servicios de formularios de terceros.

Antes de publicarlo, siga el archivo INSTRUCCIONES_APPS_SCRIPT.md. Allí se explica cómo instalar el receptor en Google Sheets y dónde pegar la URL resultante.

## Archivos principales

- index.html: cuestionario completo.
- gracias.html: confirmación después del envío.
- assets/config.js: único archivo donde se pega la URL de Apps Script.
- assets/styles.css: identidad visual rosa suave, blanca y negra con tipografía serif.
- assets/app.js: preguntas, tablas por sucursal, validaciones y envío.
- apps-script/Code.gs: código que se instala en Google Apps Script.
- INSTRUCCIONES_APPS_SCRIPT.md: instalación y publicación paso a paso.
